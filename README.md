# files/ — приложение

Здесь всё, из чего собирается сайт: материалы, рабочая версия и итоговая.

Описание проекта в целом — в `../README.md`.

---

## Три директории

| | Что это | Править |
|---|---|---|
| `src/` | материалы: аудио, обложки, шрифты, иконки | только новым содержимым |
| `dev/` | рабочая версия: страницы, стили, скрипты, шаблоны | **да, здесь** |
| `dist/` | итоговая версия после минификации, деплоится на сайт | **нет, никогда** |

Правило простое: правки вносятся в `dev/`, на сайт попадает `dist/`.
Правка в `dist/` пропадёт при следующей сборке.

Приложение самодостаточное: материалы лежат внутри, внешних ссылок в
сборке нет, каталог можно перенести целиком.

## dist/ — итоговая версия

Создаётся скриптом `../scripts/build_dist.sh`, который:

1. удаляет `dist/` целиком;
2. копирует `dev/` в `dist/`;
3. минифицирует скрипты, стили и HTML.

Отсюда следствие, о котором стоит помнить: **`dist/` после каждой сборки
теряет всё, чего нет в `dev/`**, включая каталог `pages-preview/`.
Предпросмотр кладите в `dev/pages-preview/`.

## Сборка

```bash
bash ../scripts/build_dist.sh
```

Скрипт требует `node_modules/.bin` с `terser`, `cleancss` и
`html-minifier-terser`.
