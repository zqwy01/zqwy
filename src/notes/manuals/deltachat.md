Delta Chat — это мессенджер, который работает поверх обычной электронной почты, превращая письма в чаты. Его главное преимущество в том, что для регистрации не нужен номер телефона, а переписка защищена сквозным шифрованием.

Вот пошаговая инструкция, как установить и настроить Delta Chat.

### 📥 Шаг 1: Установка приложения

Delta Chat доступен на всех основных платформах. Скачать его можно бесплатно из официальных магазинов приложений или с сайта разработчика.

- **iOS / iPhone**: Через App Store.
- **Android**: Через Google Play или F-Droid.
- **Windows**: Через Microsoft Store или с помощью команды `winget install 9PJTXX7HN3PK`.
- **macOS**: Через Homebrew (`brew install --cask deltachat`) или с официального сайта.
- **Linux**: Доступен в форматах Flatpak (`flatpak install flathub chat.delta.desktop`), AppImage, DEB, RPM и Snap.

Полный список ссылок для скачивания можно найти на [официальной странице Delta Chat](https://delta.chat/en/download).

### ⚙️ Шаг 2: Настройка аккаунта

После установки у вас есть два основных пути для начала работы.

#### Способ 1: Мгновенная настройка (рекомендуется)

Это самый быстрый и простой способ, который не требует наличия существующей электронной почты.

1.  Откройте приложение и нажмите **«Создать новый профиль»**.
2.  Введите имя или никнейм, который будут видеть ваши контакты.
3.  Нажмите **«Принять и создать профиль»**.

Готово! Приложение автоматически создаст для вас случайный аккаунт на сервере Chatmail. Вам не нужно ничего настраивать, запоминать пароли или номера телефонов — все учетные данные будут надежно храниться на вашем устройстве.

#### Способ 2: Использование существующей почты

Если вы хотите использовать для Delta Chat свой текущий адрес электронной почты:

1.  Откройте приложение и выберите **«Использовать другой сервер»** или **«Войти с помощью почты»**.
2.  Введите свой адрес электронной почты и пароль.
3.  Приложение автоматически попытается определить настройки вашего почтового сервера (IMAP/SMTP).

> **Важный совет**: Для некоторых почтовых провайдеров (например, Gmail) может потребоваться создать и использовать специальный **«пароль приложения»** вместо вашего обычного пароля от аккаунта.

Разработчики также рекомендуют завести **отдельный адрес электронной почты** специально для Delta Chat, чтобы не смешивать обычную почту с мгновенными сообщениями.

### 👥 Шаг 3: Добавление контактов

После настройки вы можете начать общение несколькими способами:

- **Сканирование QR-кода**: Самый безопасный метод. При личной встрече отсканируйте QR-коды друг друга, чтобы обменяться ключами шифрования.
- **Ссылка-приглашение**: Отправьте свою персональную ссылку-приглашение через любой другой канал (SMS, другой мессенджер, соцсети).
- **По адресу электронной почты**: Если вы знаете чей-то email, можете написать ему напрямую. Сообщение дойдет, даже если у получателя не установлен Delta Chat.

### 💻 Использование на нескольких устройствах

Вы можете использовать один и тот же аккаунт Delta Chat на телефоне и на компьютере. Для этого:

1.  На новом устройстве выберите **«Добавить как второе устройство»**.
2.  На устройстве, где аккаунт уже настроен, перейдите в **Настройки → Добавить второе устройство**.
3.  Отсканируйте QR-код, который появится на экране, новым устройством. Ваши сообщения и контакты синхронизируются.
