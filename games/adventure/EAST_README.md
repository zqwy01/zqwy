# «К Востоку» — браузерный прототип

Отдельная браузерная версия вертикального прототипа по мотивам Godot-проекта `games/to-east`.
Это не замена движку и не канонический сценарий: сюжетные тексты и эффект карты «Очарование» —
временные черновые заглушки.

Godot-проект, музыкальные файлы и `angel.webp` не изменялись. Старая игра «Клетчатый лист»
по-прежнему доступна по адресу `/index.html`.

## Запуск

```bash
cd /home/zqwy/smb/apps/tiddlywiki/tiddlywiki-data/files/games/adventure
node server.mjs
```

Открыть: <http://127.0.0.1:8130/>

Порт можно изменить:

```bash
PORT=8131 node server.mjs
```

Зависимостей нет. Если `npm` доступен, работает и `npm start`.

## Управление

- **WASD / стрелки / экранные кнопки** — ходьба.
- **E** — действие: поднять рюкзак, взять предмет, войти в испытание, коснуться Скрижали.
- **Shift / Space** — рывок (в испытании даёт короткую неуязвимость).
- **Терминал** — команды вводятся в нижнее поле: `помоги`, `осмотреться`, `рюкзак`,
  `холст`, `подойди`, `взять`, `вверх`, `вниз`, `влево`, `вправо`, `север`, `юг`,
  `запад`, `восток`, `стоп`, `очисти`, `звук`, `сброс`.
- **Холст** — команда `холст` или кнопка в интерфейсе. Элементы можно перетаскивать,
  клик выполняет элемент, быстрая команда вводится прямо на холсте.
  Кнопка **«Выйти»** видна всегда; также закрывает `Esc`.

## Проверка

```bash
node --test tests/*.test.mjs
```

Тесты проверяют генерацию комнат, старт у Скрижали, смерть и рюкзаки, нормализацию
сохранений, опасный коридор, холст, интеракции, конфигурацию испытания и безопасность
маршрутов сервера.
