Phasex:
Встречает пользователя минималистичный дизайн с небольшим количеством возможностей. С первого взгялда не супер-удобный, но в целом наполнение из четырёх осциляторов, лфо, и последовательно нескольких эффектов. Этого достаточно для создание сложных звуков. Помимо этого есть переключатели для разных режимов. Однозначный минусом является отсутсвие хоть какой-то визуализации происходящего.

Yoshimi
Интересное устройство, по борту имеется синтезатор, channel rack, send посылы и fx и несколько пресетов.
Синтезатор работает в трёх режимах - synth/bass/pad/
Поддерживает посыла для создание эффетов

Использует достататочно, можно сказать - прилично памяти: ~300 мб. К примеру популярные DAW - Fl Studio 24 которая использует примерно 150-200 мб, но это объём памяти использует только DAW, а всё же Yoshimi уже может играть музыку
