# Update 1.1

A summary of changes collected after the radio and player patch.

## Radio

- Added an in-stream hint: if playback has drifted from the broadcast time, you can sync it manually or enable auto-sync in the radio settings.
- Added a «Radio Settings» section on the `/radio/` page: manual sync, auto-sync on/off, lag threshold, and minimum check interval.
- Manual sync seeks the current track to the estimated broadcast time. Auto-sync still only kicks in when the lag is large and never rewinds.

## Player and effects

- Expanded the audio effects from the effects note: saturation, phaser, tremolo, vibrato, and ring modulator. The new effects work in live preview and when rendering to WAV/remix.
- Added a link in the effects settings to the detailed description in the notes: [Effects](/wiki/zqwy/music-effects.html).
- Player control buttons now have hover/press animations and a subtle entrance.
- The track queue opened from the player's queue button is now shown full-screen.

## Music and build

- Automatic track-duration detection during the catalog build now uses the original `orig_*` files when they sit next to the track; the catalog still lists the published formats.

## Misc

- Fixed the path to the Zemic logo in the game: it now uses `./zqwy/assets/zemic-logo.svg`.
- The project version is marked as 1.1; in the settings the version links to this update note.
