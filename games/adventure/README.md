# Клетчатый лист

Тихая браузерная история о девочке, нарисованной на клетчатом листе. Она идёт по
клеткам, собирает фрагменты воспоминаний и постепенно понимает, зачем её нарисовали.

- 7 линейных зон, в каждой — один фрагмент воспоминания;
- ни поражений, ни таймеров, ни спешки;
- вся графика рисуется процедурно на Canvas 2D;
- музыка и звуки — Web Audio + подготовленные треки;
- прогресс сохраняется в `localStorage`;
- работает без сборки и без серверной части.

## Запуск

Самый простой способ — открыть `index.html` в современном браузере (Firefox,
Chrome, Safari, Edge). Все скрипты подключены обычными `<script>`, поэтому
страница работает и через `file://`.

Если браузер ограничивает загрузку локальных файлов, запустите локальный сервер:

```bash
cd games/adventure
python3 -m http.server 8123 --bind 127.0.0.1
```

и откройте <http://127.0.0.1:8123/>.

Или воспользуйтесь готовым скриптом:

```bash
./play.sh          # выберет свободный порт и попробует открыть браузер
PORT=9000 ./play.sh
```

Сборка, `npm install` и интернет не нужны.

## Управление

| Действие | Клавиатура / мышь | Сенсор |
| --- | --- | --- |
| Шаг | `WASD` или стрелки | тап по соседней клетке |
| Поговорить с птенцом | `E` | кнопка с птенцом на HUD |
| Пауза | `Esc` или кнопка «Пауза» | кнопка «Пауза» |
| Звук вкл/выкл | `M` или кнопка звука | кнопка звука |
| Продолжить / закрыть диалог | `Enter`, `Esc`, кнопки | кнопки |

Шаг возможен только на соседнюю клетку по горизонтали или вертикали. Границы
листа мягко «упираются» и не считаются ошибкой.

### Как добавить зону

1. Добавьте объект в `ZONES` в `js/levels.js` (`cols`, `rows`, `start`, `heart`,
   `theme`, `paper`, `decor`).
2. Добавьте текст воспоминания в `MEMORIES` в том же порядке.
3. Убедитесь, что `heart` и `start` находятся внутри сетки.
4. Проверьте новую зону по чек-листу.

Код перехода сам увеличит `TOTAL` и счётчик фрагментов.

## Музыка

Используются три зацикленных фрагмента из предоставленного саундтрека
`src/tracks/mice_inside`:

| Группа | Зоны | Исходный трек |
| --- | --- | --- |
| `awakening` | 1–2 | `1_zqwy_trachea` |
| `exploration` | 3–4 | `7_zqwy_spleen` |
| `final` | 5–7, титры, финал | `4_zqwy_heart` |

Каждая группа лежит в OGG и MP3; браузер выбирает поддерживаемый формат.
Смена групп сопровождается кроссфейдом. Звук запускается после первого действия
пользователя — это требование автозапуска в браузерах. Кнопка звука и `M`
отключают и музыку, и эффекты.

## Сохранение

- `kletchaty.list.save.v1` — зона, собранные фрагменты, посещённые клетки,
  незакрытое воспоминание и признак завершения;
- `kletchaty.list.settings.v1` — громкость и выключен ли звук.

Прогресс пишется после каждого шага, сбора сердца и смены зоны. «Начать заново»
и возврат к началу после финала стирают сохранение.

## Доступность и адаптивность

- управление с клавиатуры и тач-жесты;
- `aria-live` для счётчика фрагментов и подсказок, роли `dialog` у оверлеев;
- `prefers-reduced-motion` ускоряет проявления и убирает лишнее движение;
- учтены `env(safe-area-inset-*)` для экранов с вырезом;
- интерфейс подстраивается под узкие и низкие экраны;
- при отсутствии звука или Canvas игра остаётся проходимой.

## Публикация

Игра — обычный статический сайт, сборка не нужна.

- **GitHub Pages:** положите папку `adventure` в репозиторий и включите Pages
  для нужной ветки. Если папка лежит в подкаталоге, откройте
  `https://<user>.github.io/<repo>/games/adventure/`.
- **Netlify / Vercel / Cloudflare Pages:** укажите папку `games/adventure`
  как publish directory, команда сборки не требуется.
- **Свой сервер:** скопируйте папку целиком и раздайте её любым статическим
  сервером (nginx, Caddy, `python3 -m http.server`).

Перед публикацией проверьте, что все файлы из `assets/music/` загружены и
доступны по HTTPS: браузеры не запускают звук до первого действия пользователя,
но после нажатия музыка должна играть.
