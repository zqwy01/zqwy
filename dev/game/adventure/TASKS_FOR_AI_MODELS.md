# Задачи для AI-моделей — разработка игры «Клетчатый лист»

Список того, что должны придумать, написать, сгенерировать и проверить AI-модели (разработчик + художник + дизайнер уровней) при создании игры на основе прототипа `index.html`.

---

## Роли

| Участник | Что делает |
|----------|------------|
| **AI-модель (я)** | Разработчик, архитектор кода, дизайнер уровней, художник (SVG-код), автор промптов, интегратор аудио, автор чек-листов тестирования. |
| **Человек (вы)** | Звукорежиссёр (готовые аудиофайлы), тестировщик, утвердитель контента. |

---

## 1. Концепт и дизайн уровней (придумать)

- [ ] Описать 7 зон: название, размер сетки (строки × столбцы), стартовая клетка, клетка с фрагментом, визуальная тема.
- [ ] Написать тексты 7 воспоминаний (по одной на зону) + текст финала.
- [ ] Продумать логику перехода между зонами (после сбора фрагмента → открытие следующей).
- [ ] Определить, нужны ли препятствия (стены, ямы, вода) или свободное передвижение внутри зоны (как в прототипе).
- [ ] Оформить всё в документ `LEVELS_AND_STORY.md` с данными, готовыми для вставки в код (массивы `ZONES`, `MEMORIES` и т.д.).

**Владелец задачи:** AI-модель (по согласованию с человеком).

---

## 2. Игровой код и механика (написать)

- [ ] Разбить монолитный `index.html` на модули: `index.html`, `style.css`, `game.js`, `levels.js`, `assets.js`, `audio.js`, `ui.js`.
- [ ] Реализовать игровой цикл (`requestAnimationFrame`) и состояния: `title` → `playing` → `memory` → `paused` → `credits` → `ending`.
- [ ] Движение по сетке (WASD / стрелки + тач по соседней клетке), прорисовка клетки при первом входе.
- [ ] Сбор фрагментов, счётчик `Фрагменты: X/7`, название зоны в верхней панели.
- [ ] Сохранение прогресса в `localStorage` (чтобы не начинать с первой зоны после перезагрузки).
- [ ] Поддержка `prefers-reduced-motion` и безопасных зон мобильных (`safe-area-inset`).
- [ ] Все экраны (заставка, воспоминание, пауза, титры, финал) — центрированные оверлеи.

**Владелец задачи:** AI-модель.

---

## 3. Ассеты и графика (сгенерировать / подготовить)

AI-модели не рисуют растровые PNG/JPG, но могут:

- [ ] Написать **SVG-код** для ассетов:
  - Игрок (стойка, ход, крылья, волосы).
  - Спутник — птенец-капля на плече.
  - Сердце-фрагмент (собираемый предмет, 7 штук или одно универсальное).
  - Фон — клетчатая бумага / текстура листа.
  - Кнопки UI (Начать, Продолжить, Пауза, Звук, В главное меню).
- [ ] Составить **промпты** для нейросетей (Midjourney / DALL-E / Stable Diffusion), если нужны растровые картинки.
- [ ] Подготовить техническое описание каждого ассета: размер, цветовая палитра (из `COLORS` в прототипе), стиль карандашного наброска.

**Владелец задачи:** AI-модель подготавливает SVG / промпты; человек утверждает и кладёт файлы в `/assets/images/`.

---

## 4. Аудио (интеграция готовых файлов)

Человек предоставляет готовые файлы, AI-модель подключает их в код:

- [ ] Заменить процедуральный звук (Web Audio осцилляторы) на воспроизведение файлов через `new Audio()` / Web Audio API.
- [ ] 3 фоновых трека по группам зон: пробуждение, исследование, финал/эмоция.
- [ ] Звуковые эффекты: шаг по клетке, сбор фрагмента, открытие воспоминания, клик кнопки, пауза.
- [ ] Кнопка звука вкл/выкл в UI паузы.
- [ ] Убедиться, что аудио не блокируется браузером (нужно взаимодействие пользователя перед запуском).

**Владелец задачи:** человек готовит файлы → AI-модель интегрирует.

---

## 5. UI/UX и адаптивность

- [ ] Верхняя панель: счётчик фрагментов, название текущей зоны.
- [ ] Адаптивный масштаб холста под десктоп и мобильные устройства.
- [ ] Тач-управление: тап на соседнюю клетку = ход.
- [ ] Поддержка разных соотношений сторон экрана без обрезки важного UI.

**Владелец задачи:** AI-модель.

---

## 6. Тестирование (сценарии для проверки)

AI-модель составляет чек-лист, человек выполняет проверку:

- [ ] Пройти все 7 зон от начала до финала без застреваний и багов.
- [ ] Проверить сохранение прогресса после перезагрузки страницы.
- [ ] Проверить тач-управление на телефоне и планшете.
- [ ] Проверить звук: включение/выключение, фоновая музыка, звуковые эффекты.
- [ ] Проверить игру на разных браузерах (Chrome, Firefox, Safari, Edge).
- [ ] Проверить `prefers-reduced-motion` (отсутствие раздражающих анимаций).
- [ ] Проверить работу на разных размерах экрана (мобильный, планшет, десктоп).

**Владелец задачи:** AI-модель пишет сценарии; человек тестирует.

---

## 7. Деплой и релиз

- [ ] Подготовить инструкцию по размещению на хостинге (GitHub Pages, Netlify, Vercel или свой сервер).
- [ ] Проверить, что игра открывается по HTTPS и аудио не блокируется браузером.
- [ ] Опубликовать рабочую версию и прислать ссылку.

**Владелец задачи:** AI-модель инструктирует; человек публикует.
