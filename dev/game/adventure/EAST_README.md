# «К Востоку» — браузерный прототип

Отдельная браузерная версия вертикального прототипа по мотивам Godot-проекта `games/to-east`.
Это не замена движку и не канонический сценарий: сюжетные тексты и эффект карты «Очарование» —
временные черновые заглушки.

Godot-проект, музыкальные файлы и `angel.webp` не изменялись. Старая игра «Клетчатый лист»
по-прежнему доступна по адресу `/index.html`, новый прототип — по адресу `/`.

## Запуск

```bash
cd /home/zqwy/smb/apps/tiddlywiki/tiddlywiki-data/files/games/adventure
node server.mjs
```

Открыть: <http://127.0.0.1:8130/>

Порт можно изменить:

```bash
PORT=8131 node server.mjs
```

Зависимостей нет. Если `npm` доступен, работают `npm start`, `npm run dev` и `npm test`.

## Управление

- **WASD / стрелки / экранные кнопки** — плавная ходьба.
- **E** — действие: поднять рюкзак, взять предмет, войти в испытание, коснуться Скрижали.
- **Shift / Space** — рывок (в испытании даёт короткую неуязвимость).
- **ЛКМ по сцене** — маршрут к точке; **удержание ЛКМ** — следование за курсором.
  Курсор можно отключить в настройках.
- **Терминал** — поле ввода с автодополнением, историей `↑`/`↓` и подсказкой
  «Введите команду и нажмите отправить».

### Команды

| Команда | Что делает |
|---|---|
| `помоги` | Список **доступных** команд; закрытые сюжетом команды не выводятся. |
| `осмотреться` | Описание текущей комнаты. |
| `рюкзак` | Содержимое рюкзака и потерянные рюкзаки. |
| `холст` | Бесконечный рабочий стол. |
| `сюжет` | Сюжетная схема с ветками и связями `->`. |
| `история` | Использованные команды — тот же буфер, что и `↑`/`↓`. |
| `взять` | Поднять предмет или рюкзак рядом. |
| `подойди` | Плавно подойти к ближайшему объекту. |
| `идти вверх` · `идти вниз` · `идти влево` · `идти вправо` | Плавная ходьба в сторону. По умолчанию 1 секунда. |
| `идти вниз 10` | Идти вниз 10 секунд (аналогично для остальных сторон). |
| `север` · `юг` · `запад` · `восток` | Переход через выход комнаты. |
| `стоп` | Остановить движение и следование за курсором. |
| `рывок` | Короткий рывок в последнем направлении. |
| `очисти` | Очистить запись действий. |
| `звук` | Включить или выключить звук. |
| `язык` · `language` | Переключить русский/английский. |
| `настройки` · `settings` | Открыть настройки. |
| `сброс` | Начать лабиринт заново (с подтверждением). |
| `очарование`, `мел`, `карта` | Появляются только после сюжетной разблокировки. |

Настройки ходьбы (`идти вниз` без числа), управление курсором, фильтры записи действий,
язык, музыкальный плеер и сохранения находятся в разделе **Настройки** — вне терминала.

## Запись действий

Логи — это запись действий (журнал шагов), а не отдельная «консоль». Каждая строка имеет
источник: `Команда`, `Терминал`, `Система`, `Лабиринт`, `Действие`, `Ошибка`, `Эхо`.
В настройках источники можно включать и выключать. Метки «Система» и «Лабиринт» выделены
яркими цветами.

## Рабочий стол (холст)

- Открывается командой `холст` или кнопкой `⌗`.
- Сетка непрерывна во все стороны; стол можно двигать фоном и масштабировать колесом/кнопками.
- **`+`** у команды добавляет ноду команды.
- **`->`** включает режим связи: выберите две ноды, между ними появится видимый вектор.
- Визуализация клавиатуры интерактивна: нажатие клавиши (экранной или физической) сразу
  добавляет клавишу и связанную с ней команду.
- Закрытые команды и карты не показываются на палитре, пока не открыты сюжетом.
- Кнопка **Выход** находится в одной колонке с управлением масштабом; закрывает также `Esc`.

## Сохранение

Состояние автоматически хранится в `localStorage` под ключом `toEast.save.v1`.
Кнопки **Сохранить**, **Загрузить**, **Выгрузить мир**, **Импорт мира** и **Сброс** находятся
только в настройках. Экспорт скачивает JSON с текущим миром.

## Проверка

```bash
node --test tests/*.test.mjs
```

Тесты проверяют генерацию комнат и проходов, шанс первой сюжетной комнаты (25%),
старт у Скрижали, смерть и рюкзаки, нормализацию сохранений, опасный коридор,
разблокировку команд, холст и связи, интеракции, конфигурацию испытания,
двуязычный контент и безопасность маршрутов сервера.
