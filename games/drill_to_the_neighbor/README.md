# БУР ДРУИДА — ритуал соседнего кургана

Один трек, один забег, один бур. Ты — дух друида в круглом кургане, который
пробивает ход к соседнему могильнику. Музыка задаёт каждый удар: бей в такт,
кроши корни и камни, держи комбо и доведи глубину до **65%** к концу трека.

Игра сделана на чистом HTML/CSS/JS без сборки. Внутреннее разрешение мира —
400×400, картинка масштабируется с `image-rendering: pixelated`.

## Запуск

```bash
cd games/drill_to_the_neighbor
./play.sh
```

Или вручную:

```bash
cd games/drill_to_the_neighbor
python3 -m http.server 8080
# открыть http://localhost:8080/
```

`play.sh` поднимает локальный сервер и открывает страницу. Можно открыть
`index.html` напрямую (`file://`), но браузер может заблокировать загрузку
аудио. Для игры нужны звук и наушники.

## Управление

| действие | клавиатура | телефон |
|----------|------------|---------|
| движение | `WASD` / стрелки | левый джойстик |
| удар в такт | `ПРОБЕЛ` / `J` / клик по арене | кнопка **БУР** |
| пауза | `P` / `ESC` | кнопка `II` в HUD |
| продолжить | `P` / `ESC` / `ПРОБЕЛ` | кнопка в паузе |
| звук | `M` | кнопка `♪` в HUD |
| заново | `R` в паузе / на итогах | кнопка **ЕЩЁ РАЗ** |

Первый запуск музыки происходит только после нажатия **НАЧАТЬ РИТУАЛ**
(браузерное требование). Трек предзагружается заранее, но не играет.

## Забег

- **5 жизней.** Шип снимает 1, камень — 2. После раны друид ненадолго
  неуязвим, комбо сбрасывается, глубина немного проседает.
- **Удар в такт.** Идеально — ≤ 85 мс от удара, хорошо — ≤ 170 мс.
  Успешный удар даёт очки, глубину и импульс, который уничтожает шипы и
  камни рядом с друидом.
- **Комбо** растёт за попадания в такт. Промах по такту или удар «не в такт»
  сбрасывает серию. Каждые **24 комбо** — +1 жизнь (до 5).
- **Опасность приходит по музыке.** За один такт до появления шипа или камня
  на краю круга загорается предупреждающее кольцо. Через такт опасность
  выходит из земли и ползёт к друиду.
- **Победа** — к концу трека глубина ≥ 65%. **Поражение** — 0 жизней или
  слишком мелкий проход. На итогах видны глубина, очки, максимум комбо,
  идеальные/хорошие удары и промахи.

Лучший забег хранится в `localStorage`.

## Музыка и синхронизация

Трек: `assets/drill_to_the_neighbor.mp3` (Ogg — запасной вариант), копия
исходного `8_zqwy_drill_to_the_neighbor.wav`. Исходник не изменялся.

- 157.0 с, 44.1 кГц, стерео, 32-bit float PCM WAV.
- Теги: **90 BPM**, тональность **Ebm**, жанр hardcore, альбом `voidstorm`.
- Игровой отрезок: **0:00–2:35** (155.1 с). Последний слышимый удар — около
  154.6 с, дальше хвост/тишина.
- Секции: `ТИШИНА КУРГАНА` (0–6.3), `ПРОБУЖДЕНИЕ КОРНЕЙ` (6.3–36),
  `ПРИЛИВ` (36–44), `ГЛУБОКИЙ ХОД` (44–108), `СЕРДЦЕ КУРГАНА` (108–112),
  `ДОРОГА К СОСЕДУ` (112–148), `ПОРОГ` (148–155.1).

MIDI-партитуры у трека нет, поэтому точная нотная синхронизация не
заявляется. Вместо неё `tools/build_chart.py` измеряет аудио: декодирует
источник через ffmpeg, считает спектральный поток (STFT 2048/512), подгоняет
сетку 90 BPM к низам/атакам и снимает энергию вокруг каждого удара.
Получается **223 удара** на сетке 0.6667 с, от 6.635 до 154.635 с; акценты,
сильные доли и границы секций записаны в `js/chart.js`. Это надёжный
ритмический фолбэк, а не MIDI-транскрипция.

Во время игры:

- часы берутся из `AudioBufferSourceNode` и `AudioContext.currentTime` с
  поправкой на `outputLatency`;
- кольцо-подсказка сжимается к друиду ровно к следующему удару из чарта;
- предупреждения и опасности привязаны к ударам чарта (предупреждение — за
  один такт, выход из земли — на следующем такте);
- энергия секций и полосы анализатора двигают огонь, камни, пульс рамки и
  частицы;
- пауза останавливает и музыку, и игровое время; продолжение стартует с той
  же точки;
- поражение обрывает трек с коротким vinyl-stop скрежетом, **ЕЩЁ РАЗ**
  запускает и игру, и музыку с нуля.

На Bluetooth-наушниках задержка может быть больше, чем сообщает браузер;
в этом случае удар будет ощущаться на волосок позже картинки. Это ограничение
браузерного аудио, а не отдельный таймер игры.

## Эстетика

Палитра и настроение взяты с `design.jpg`: тёплый уголь `#2e110f`, кора
`#581a15`, едкий оранжевый `#fe7844` / `#f76032`, кость `#faf1ef`, приглушённый
мокрый лиловый `#69474e` / `#a07891`. Референс **не** используется как фон —
вся сцена, камни, руны, друид и опасности нарисованы процедурно на canvas.
Мистика и древность без хоррора, крови и расчленения: только корни, камни,
искры и огамические насечки.

## Файлы

```
index.html        — точка входа, HUD, меню, экраны итогов
style.css         — раскладка, масштабирование, touch-управление
js/chart.js       — измеренный ритм-чарт (генерируется, не править вручную)
js/core.js        — чистая логика: судейство, сложность, прогресс, PRNG
js/art.js         — процедурная пиксельная графика и эффекты
js/audio.js       — буфер, точные часы, анализатор, vinyl-stop
js/game.js        — цикл, опасности, HUD, ввод, пауза, победа/поражение
assets/…          — mp3/ogg трека и пиксельный шрифт Tiny5
tools/build_chart.py — воспроизводимая генерация чарта
tools/selftest.mjs   — локальные проверки логики и чарта
play.sh           — локальный сервер
```

## Проверки

```bash
node --check js/*.js
node tools/selftest.mjs
```

`selftest.mjs` проверяет сетку ударов, окна судейства, секции, спавн
опасностей, диапазон скоростей, достижимость 65% и наличие файлов. Отдельно
проверено, что при сильной игре цель берётся, при средней — на грани, а при
слабой — нет. Графика и звук требуют браузера; запускай через `play.sh`.

Дополнительно игра прогнана в headless Firefox (geckodriver):

- **102/102** проверки основного потока: загрузка, старт только после кнопки,
  часы от аудио, спавн по ударам чарта, удар в такт, пауза/продолжение без
  рассинхрона, mute, поражение с vinyl-stop, рестарт с нуля, победа, возврат
  в меню;
- **110/110** проверок раскладки в iframe с точным размером экрана:
  320×568, 360×640, 390×844, 667×375, 844×390, 768×1024 — HUD, меню,
  кнопки и арена не выходят за экран;
- touch-управление: джойстик двигает и возвращается в центр, кнопка **БУР**
  даёт perfect-попадание и визуальное нажатие;
- естественное окончание трека проверено и для победы (`drill=70`), и для
  поражения (`drill=40`): поражение сразу останавливает звук и очищает
  источник.

Эти проверки не заменяют ручную игру в наушниках: задержка Bluetooth-аудио
зависит от устройства.

Tiny5 — пиксельный шрифт с кириллицей (OFL), скопирован из соседнего проекта
`games/umbrella`; исходный WAV и `design.jpg` не изменялись.
