Delta Chat ist ein Messenger, der auf normaler E-Mail aufbaut und Nachrichten in Chats verwandelt. Sein größter Vorteil: Zur Registrierung ist keine Telefonnummer nötig, und die Unterhaltungen sind Ende-zu-Ende-verschlüsselt.

Hier ist eine Schritt-für-Schritt-Anleitung zur Installation und Einrichtung von Delta Chat.

### 📥 Schritt 1: App installieren

Delta Chat ist auf allen gängigen Plattformen verfügbar. Kostenlos herunterladen kann man es über offizielle App-Stores oder von der [Website der Entwickler](https://delta.chat/ru/download).

- **iOS / iPhone**: Über den [App Store](https://apps.apple.com/app/delta-chat/id1459523234).
- **Android**: Über [Google Play](https://play.google.com/store/apps/details?id=chat.delta) oder [F-Droid](https://f-droid.org/app/com.b44t.messenger).
- **Windows**: Über den [Microsoft Store](https://apps.microsoft.com/detail/9pjtxx7hn3pk) oder mit dem Befehl `winget install 9PJTXX7HN3PK`.
- **macOS**: Über [Homebrew](https://formulae.brew.sh/cask/deltachat) (`brew install --cask deltachat`) oder von der [offiziellen Website](https://delta.chat/ru/download).
- **Linux**: Verfügbar als [Flatpak](https://flathub.org/apps/chat.delta.desktop) (`flatpak install flathub chat.delta.desktop`), AppImage, DEB, RPM und Snap.

Eine vollständige Liste der Download-Links findet sich auf der offiziellen Delta-Chat-Seite: [https://delta.chat/ru/download](https://delta.chat/ru/download).

### ⚙️ Schritt 2: Konto einrichten

Nach der Installation gibt es zwei grundlegende Wege, um zu beginnen.

#### Methode 1: Soforteinrichtung (empfohlen)

Das ist der schnellste und einfachste Weg und setzt kein bestehendes E-Mail-Konto voraus.

1.  Öffnen Sie die App und tippen Sie auf **„Neues Profil erstellen"**.
2.  Geben Sie den Namen oder Spitznamen ein, den Ihre Kontakte sehen sollen.
3.  Tippen Sie auf **„Akzeptieren und Profil erstellen"**.

Fertig! Die App erstellt automatisch ein zufälliges Konto auf einem Chatmail-Server für Sie. Sie müssen nichts einrichten, keine Passwörter oder Telefonnummern merken — alle Zugangsdaten werden sicher auf Ihrem Gerät gespeichert. Mehr über Chatmail-Server erfahren Sie auf der [offiziellen Website des Projekts](https://chatmail.at).

#### Methode 2: Bestehendes E-Mail-Konto verwenden

Wenn Sie Ihre aktuelle E-Mail-Adresse für Delta Chat nutzen möchten:

1.  Öffnen Sie die App und wählen Sie **„Anderen Server verwenden"** oder **„Mit E-Mail anmelden"**.
2.  Geben Sie Ihre E-Mail-Adresse und Ihr Passwort ein.
3.  Die App versucht automatisch, die Einstellungen Ihres Mailservers (IMAP/SMTP) zu ermitteln.

> **Wichtiger Hinweis**: Bei manchen E-Mail-Anbietern (etwa Gmail) kann es nötig sein, ein spezielles **„App-Passwort"** zu erstellen und zu verwenden statt Ihres üblichen Kontopassworts. Eine Anleitung zum Erstellen eines Gmail-App-Passworts finden Sie auf [der Google-Hilfeseite](https://support.google.com/accounts/answer/185833).

Die Entwickler empfehlen außerdem, **eine separate E-Mail-Adresse** eigens für Delta Chat einzurichten, damit normale E-Mails nicht mit Sofortnachrichten vermischt werden.

### 👥 Schritt 3: Kontakte hinzufügen

Nach der Einrichtung können Sie auf mehrere Arten kommunizieren:

- **QR-Code scannen**: Die sicherste Methode. Scannen Sie bei einem persönlichen Treffen gegenseitig die QR-Codes, um Verschlüsselungsschlüssel auszutauschen.
- **Einladungslink**: Senden Sie Ihren persönlichen Einladungslink über einen anderen Kanal (SMS, einen anderen Messenger, soziale Netze).
- **Über die E-Mail-Adresse**: Wenn Sie jemandes E-Mail-Adresse kennen, können Sie ihm direkt schreiben. Die Nachricht kommt auch an, wenn der Empfänger Delta Chat nicht installiert hat.

Weitere Anwendungsfälle und Antworten auf häufige Fragen finden Sie in der [offiziellen Delta-Chat-Dokumentation (FAQ)](https://delta.chat/ru/help).

### 💻 Nutzung auf mehreren Geräten

Sie können dasselbe Delta-Chat-Konto auf dem Telefon und am Computer nutzen. Dafür:

1.  Wählen Sie auf dem neuen Gerät **„Als zweites Gerät hinzufügen"**.
2.  Gehen Sie auf dem Gerät, auf dem das Konto bereits eingerichtet ist, zu **Einstellungen → Zweites Gerät hinzufügen**.
3.  Scannen Sie den auf dem Bildschirm erscheinenden QR-Code mit dem neuen Gerät. Ihre Nachrichten und Kontakte werden synchronisiert.

Wenn Sie eine ausführlichere Anleitung benötigen, finden Sie die vollständige Dokumentation im [offiziellen Delta-Chat-Wiki](https://deltachat.wiki).
