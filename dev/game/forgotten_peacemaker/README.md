# Ветер гложет скелет забытого миротворца

Атмосферный симулятор без проигрыша. В выжженной пустоши сидит скелет
человека, который когда-то остановил войну, но чьё имя никто не сохранил.
Игрок управляет ветром: направление и сила определяют, как быстро сдувается
пыль с костей. В пыли всплывают светящиеся обрывки памяти — их нужно нажать,
чтобы прочитать историю миротворца.

## Механика

- **Ветер.** Ползунки задают направление (0° — на север) и силу. Перетаскивание
  по сцене ставит ветер рукой: угол — направление, расстояние от центра — сила.
  Стрелки тоже работают.
- **Обдувание.** Чем сильнее ветер, тем быстрее накапливается «память» и открываются
  новые обрывки (всего 8). Порыв ускоряет процесс.
- **Кость.** Сильный ветер стирает кость: индикатор «КОСТЬ» падает, скелет бледнеет.
  Это не проигрыш — можно укрыть его тканью, и прочность вернётся. Уже найденные
  обрывки не теряются.
- **Прислушаться.** Показывает подсказку о ближайшем непрочитанном обрывке
  и немного добавляет обдувания.
- **Дневник.** Все найденные фрагменты сохраняются на странице. После восьмого
  открывается финальная эпитафия.

## Управление

| Действие | Управление |
| --- | --- |
| Направление / сила | ползунки, стрелки или перетаскивание по пустоши |
| Порыв | пробел или кнопка «ПОРЫВ» |
| Прислушаться | `E` |
| Укрыть / открыть | `H` |
| Звук | кнопка «ЗВУК» |
| Заново | `R` |

## Техническое

Отдельное статическое приложение: `index.html`, `style.css`, `js/audio.js`
(процедурный ветер, гул, порыв и колокольчики через Web Audio) и `js/game.js`
(состояние, частицы на canvas, обрывки памяти, дневник). Внешних файлов и
зависимостей нет. Как и другие игры, публикуется в `dist/game/` без минификации —
`scripts/build_dist.sh` пропускает всё, что начинается с `game/`.

Карточка добавлена в `dev/game/index.html`, поэтому игра попадает в поисковый
индекс; для фразы названия и «миротворец / forgotten peacemaker» есть группа
синонимов в `dev/data/search-synonyms.json`.
