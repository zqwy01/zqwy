# `scripts/radio.js` → `scripts/radio/`

Круглосуточное радио: детерминированная программа от фиксированной epoch,
текущий/следующий трек, синхронизация по времени и блокировка плеера на время
эфира.

| Файл | Что внутри |
| --- | --- |
| `context.js` | `P` с константами расписания, состоянием эфира и двуязычными строками; `CATALOG_URL` от `import.meta.url` |
| `i18n.js` | `lang()`, `text()`, `clock()` |
| `schedule.js` | хэш трека, пул, программа на сутки, позиция, переходы по блокам |
| `ui.js` | захват DOM, программа дня, статус, сообщения синхронизации |
| `playback.js` | `player()`, `applyTrack()`, `tick()`, `start()`, `stop()` |
| `settings.js` | `zqwy.radio.settings.v1`, пороги и интервалы ресинхронизации |
| `init.js` | загрузка каталога и первичный рендер |
| `events.js` | кнопки, ползунки настроек, `zqwy:playerstate`, `zqwy:languagechange`, `zqwy:pagechange` |

Каталог берётся по URL, привязанному к модулю (`../../../data/` от
`scripts/radio/context.js`). Раньше `../../data/` от `document.baseURI` давал
корень сервера, и при прямом открытии `/radio/` программа не строилась.
