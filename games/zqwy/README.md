# Лабиринт сознаний · Zemic

Браузерный прототип о Zemic, который уже находится внутри Лабиринта сознаний. Это статическое приложение на HTML, CSS и JavaScript: без сборщика, backend, базы данных и Node.js на стороне игрока.

Мир Лабиринта создаётся лениво по чанкам, поэтому он не заканчивается на стартовом участке и не требует заранее построенной карты. Новый запуск получает новый случайный seed, а сохранённый мир продолжается с тем же seed.

## Быстрый запуск

1. Откройте `index.html` в современном браузере.
2. Либо запустите статическую раздачу из корня этой директории:

```bash
python3 -m http.server 8000
```

и откройте `http://127.0.0.1:8000/`.

Для GitHub Pages достаточно опубликовать содержимое этой директории как есть. Сборка не требуется. Все пути к ресурсам относительные.

`localStorage` может быть ограничен при открытии через `file://` или в приватном режиме. Игра в этом случае продолжает работать, но прогресс между перезагрузками может не сохраняться.

## Управление

| Действие | Клавиатура | Сенсорный экран |
| --- | --- | --- |
| Движение в восьми направлениях | `W` `A` `S` `D` / стрелки | экранный D-pad |
| Идти к точке | ЛКМ по миру | касание мира |
| Следовать за курсором | удержание ЛКМ | удержание касания |
| Взаимодействие | `E` | кнопка действия `✦` |
| Команда терминала | `Enter` | поле ввода |
| История команд | `↑` / `↓` в поле ввода, команда `история` | — |
| Вернуться / закрыть представление | `Esc` | кнопки `×`, «← к столу» |
| Разделитель игры и терминала | `↑` / `↓` / `Home` при фокусе на разделителе | перетаскивание за полосу |
| Масштаб стола | колесо мыши | щипок двумя пальцами, кнопки `−` / `100%` / `+` |
| Двигать стол | ЛКМ по пустому месту | перетаскивание пустого места |
| Закрыть печать в испытании | `Space` | кнопка `✦` |

По умолчанию не назначено ни одной «быстрой» клавиши для рюкзака, карты, стола, осмотра или остановки. Такие привязки создаются игроком на столе: одна клавиша может запускать несколько связанных целей. Базовыми остаются только движение, `E`, `Enter`, `Space` в испытании и `Esc` для закрытия представлений.

Открытые вкладки терминала — рюкзак, карта, сюжет, стол, настройки, музыка и настройки шрифта — не блокируют управление: Zemic можно вести клавишами, ЛКМ или геймпадом, не закрывая представление. Исключение — испытание: это отдельный режим, который приостанавливает мир. `Esc` закрывает активную вкладку и возвращает основную.

Подсказка по управлению не занимает отдельную полосу под экраном: при запуске одним системным сообщением в лог выводятся версия ядра, время загрузки мира, число комнат и чанков, seed и полная справка по управлению. Отдельных визуальных баннеров и подсказок на игровом холсте нет.

В игре используется собственный курсор: системный указатель над игровым холстом скрыт, а позицию показывает кольцо с точкой. Оно реагирует на нажатие ЛКМ. На кнопках интерфейса остаётся обычный курсор.

Движение из терминала плавное и длится по времени: `идти вниз` — одна секунда, `идти вниз 10` — десять секунд.

Ходьба по ЛКМ использует поиск пути по проходимым клеткам: Zemic обходит стены и препятствия, а не идёт напрямую сквозь них. Если точка недоступна, выбирается ближайшая достижимая клетка. Путь начинается из текущей позиции героя и заканчивается у самого курсора, поэтому при удержании ЛКМ нет рывков назад к центру клетки и цель не «прилипает» к тайлу. При удержании маршрут пересчитывается только тогда, когда курсор переходит на другую целевую клетку.

## Команды и помощь

Терминал понимает команды: `помоги`, `привет`, `ты куда пропал`, `подойди`, `идти вверх` / `идти вниз` / `идти влево` / `идти вправо` (можно с длительностью), `стоп`, `осмотреться`, `сюжет`, `рюкзак`, `карта`, `стол`, `пометить`, `очаровать`, `настройки`, `логгирование`, `музыка`, `история`, `язык`, `сохранить`, `загрузить`, `экспорт`, `очисти`, `новая игра`. Короткие формы `вверх`/`вниз`/`влево`/`вправо` и английские псевдонимы (`help`, `walk down`, `stop`, `history`, `language`, `save`, `load`, `export` и другие) тоже работают. Для немецкого доступны `hilfe`, `laufen oben`, `halt`, `einstellungen`, `speichern`, `laden`, `musik`, `sprache` и другие псевдонимы.

`помоги` выводит только открытые группы команд:

- `основное` — терминал и ориентирование;
- `сюжет` — ветвь истории, находки и цель;
- `движение` — шаги по времени и остановка;
- `рюкзак` — переносимое и найденное;
- `карта` — путь и метки;
- `стол` — рабочая поверхность и клавиши;
- `карты` — способности;
- `логгирование` — запись шагов, действий, команд и источников;
- `терминал` — настройки, язык и история команд;
- `данные` — сохранение, загрузка и экспорт мира;
- `музыка` — музыкальный плеер.

`помоги движение` раскрывает одну группу. Закрытая группа вообще не попадает в список: пока рюкзак, карта или стол не открыты сюжетом, `помоги` о них не упоминает. Те же открытые группы используются в панели добавления на столе, чтобы не выводить все команды сразу.

Команда `история` выводит буфер введённых команд — тот же, который листается клавишами `↑` / `↓`. `язык английский` / `язык немецкий` / `язык русский` переключает интерфейс и терминал; в английском режиме доступны английские псевдонимы команд, в немецком — немецкие. Немецкая локализация — частичный оверлей: интерфейс, команды, сюжетные сцены и описания переведены, редкие служебные фрагменты могут оставаться на английском.

Автодополнение работает как прогноз прямо в поле ввода: известная часть команды остаётся обычным текстом, а вероятное продолжение показывается полупрозрачным текстом сразу после курсора. Отдельного столбца или списка подсказок в терминале нет. `Tab` принимает продолжение, `Esc` скрывает его, `↑` / `↓` по-прежнему листают историю. В подсказку попадают направления и длительность для `идти`, значения для `язык` и `логгирование`, открытые группы для `помоги`, разделы `настройки`, действия `музыка` и команды из истории.

Команда `новая игра` удаляет сохранение, создаёт новый случайный seed, заново строит стартовый чанк и сбрасывает открытия, предметы, метки и элементы стола. Seed нового мира выводится в лог. Сохранение, загрузка и экспорт мира доступны также кнопками в `настройки` → «Данные».

## Запись действий

«Запись действий» — это фильтр полезной текстовой информации, а не отдельная система слежки. Например, категория «движение» записывает шаги персонажа. Команда `логгирование` управляет записью событий в терминал. По умолчанию лог выключен, но категории уже настроены:

- `логгирование вкл` / `логгирование выкл` — весь лог;
- `логгирование всё` / `логгирование ничего` — включить или выключить все категории;
- `логгирование движение` — шаги персонажа;
- `логгирование действия` — взаимодействия и предметы;
- `логгирование команды` — введённые и связанные команды;
- `логгирование терминал` — сообщения самого терминала;
- `логгирование сцены` — сюжетные сцены и реплики;
- `логгирование система` — системные сообщения;
- `логгирование мир` — загрузка мира, чанки и seed.

При включённом логе шаг появляется в терминале строкой с меткой «шаг». Категории можно переключать и в `настройки` → «Терминал». Настройки записи сохраняются в `localStorage` вместе с остальными настройками терминала.

## Сюжет

Команда `сюжет` открывает отдельное представление в терминале — только для чтения. Оно оформлено как стол: карточки этапов расположены колонками по глубине ветви, а связи нарисованы изогнутыми стрелками, поэтому схему можно читать как сюжетный граф. Граф не блокирует игру: пока он открыт, Zemic можно вести клавишами или ЛКМ, а `Esc` возвращает основную вкладку терминала.

В представлении показаны:

- всё дерево этапов с состояниями «пройдено», «сейчас» и «закрыто»;
- побочные ветви, включая возвращение после гибели.

Отдельного контейнера с описанием текущего этапа нет: остаётся только полотно графа. Карточки этапов можно перетаскивать левой кнопкой мыши, а пустое полотно — панорамировать той же кнопкой. Позиции карточек и сдвиг полотна сохраняются в текущей сессии и сбрасываются при новой игре.

В графе нет кнопок перехода: это карта пути, а не меню телепортации. Сюжетные сцены по-прежнему выводятся в общий лог терминала.

## Прогрессия и открытия

В начале доступны только базовые команды и движение. Рюкзак, карта и стол открываются по истории:

- **Скрижаль** открывает `рюкзак` и `стол` — при первом входе в комнату или по действию `E` рядом со Скрижалью.
- **Обрывок карты** в Кладовой открывает `карту`; без него карта отвечает, что пока недоступна.
- `пометить` требует угольный мелок, а `очаровать` — карту «Очарование».

Закрытые команды не выполняются: терминал отвечает подсказкой об открытии. В `помоги` и в панели стола они не показываются, пока соответствующая группа не откроется сюжетом. Кнопки рюкзака, карты, стола и способностей также скрыты до открытия. Открытия входят в сохранение.

## Интерфейс: игра и терминал

Экран разделён на две основные области. Верхняя — только изображение игры: мир, виньетка, сенсорное управление и сцена испытания. В ней нет заголовков комнат, HUD, подсказок, уведомлений и кнопок систем. Нижняя — терминал, внутри которого живут все тексты и системные представления:

- основной лог команд, строка контекста «рядом: …» и поле ввода с подсказкой «Введите команду и нажмите отправить»;
- рюкзак со списком предметов и кнопками действий;
- карта участка 7×5 комнат, которая следует за игроком;
- стол с инструментами, масштабом, панорамированием, клавишами, предметами и командами; с устройством «мышь» в списке схем управления и закрытием через крестик `×`;
- полный просмотр карты с возвратом в рюкзак или на стол;
- общие настройки: язык, шрифт, музыка и данные;
- отдельное представление настроек шрифта: общий размер и размеры по разделам;
- встроенный музыкальный плеер: воспроизведение, пауза, стоп, перемотка, громкость, волновая дорожка и ускоренное/замедленное воспроизведение;
- граф сюжета;
- статус испытания.

Сюжетные сцены, гибель и результат испытания не открывают отдельных экранов и не требуют кнопки «Дальше»: их текст добавляется прямо в лог терминала. Реплики помечаются говорящим (`КЛАДОВАЯ`, `КРУГ`, `СКРИЖАЛЬ`, `ЛАБИРИНТ`), системные сообщения, ответы терминала и записи лога используют единый служебный цвет, введённые команды — метку `Zemic:`. Строка «рядом: коснуться Скрижали · E» выводится в терминале; на игровом холсте подсказок нет.

### Правила терминала

Эти правила обязательны для всех будущих патчей:

- в терминале нет часов, текущего времени и меток времени у сообщений — это поток текста, а не журнал;
- над терминалом нет строки состояния и подписи «терминал»; лог начинается сразу с сообщений;
- команда `часы` и её псевдонимы не возвращаются, как и отдельная группа команд для времени.

### Адаптивная компоновка

Игра и терминал занимают весь viewport, а не вписываются в жёсткое соотношение 9:16. На узком экране области складываются вертикально, на широком (16:9 и шире) игровая область расширяется по горизонтали и показывает больше мира. Камера при этом остаётся строго центрирована на Zemic. Safe-area-отступы учитываются.

Пиксельная графика чувствительна к пропорциям, поэтому приложение проверяет соотношение сторон окна при запуске и при каждом изменении размера или ориентации. Если оно выходит за допустимый диапазон (примерно от 1.32:1 до 2.4:1), в терминал выводится текстовое сообщение с фактическим соотношением. Отдельного визуального баннера или предупреждения на холсте нет. Сообщение появляется один раз при выходе за диапазон и не повторяется при каждом шаге изменения размера; после возврата в норму проверка снова готова выдать предупреждение.

### Шрифты и типографика

Все размеры текста собраны в отдельном модуле `js/fonts.js` и в токенах `--fs-micro` … `--fs-h1`, которые считаются от одной переменной `--type-unit`. Поэтому кнопки, подписи, терминал и стол больше не расходятся по размеру. Глобальный размер шрифта задаётся числом, ползунком и пресетами 12/14/16/18 px в диапазоне 10–24 px; минимальные подписи при этом остаются читаемыми. Размеры шрифта вынесены в отдельный раздел настроек «Настройки: шрифт», куда ведёт кнопка из общих настроек. Внутри него можно отдельно переопределить терминал и стол. Переопределение `0` означает «наследовать общий размер»; кнопка «авто» сбрасывает его. Значения хранятся вместе с остальными настройками терминала.

Заголовки настроек оформлены иерархией: «Настройки» — H1, разделы («Язык», «Шрифт», «Музыка», «Данные») — H2. Подразделы «Настройки: терминал», «Настройки: шрифт» и «Музыка» открываются из общего раздела и возвращают в него по кнопке «← общие настройки».

### Разделитель

Между областями есть разделитель. Его можно перетаскивать мышью, пальцем или клавишами `↑`/`↓`; `Home` возвращает пропорцию по умолчанию. Минимальная высота игровой области — 170 px, терминала — 150 px, поэтому ни одна сторона не может исчезнуть. Пропорция сохраняется в `localStorage` под ключом `zqwy.labyrinth.split.v1`; по умолчанию игре достаётся 56% высоты. При открытии систем терминал при необходимости расширяется до минимальной доли, чтобы содержимое оставалось читаемым.

### Стол

Стол открывается прямо в терминале и не перекрывает игру отдельным окном. Заголовок — «Стол». На нём свободно размещаются элементы: предметы, команды и отдельные клавиши. Короткое нажатие на предмет или команду выполняет её; перетаскивание меняет положение; кнопка `×` убирает элемент. Кнопка добавления обозначена просто символом `+`, а режим связи — стрелкой `→`.

Элементы можно перетаскивать в любую точку рабочей поверхности, вплоть до самых краёв. Внутренних отступов и ограничений положения больше нет: и при перетаскивании, и при загрузке макета координаты ограничены только диапазоном `0…1`, а не безопасной серединой.

Сетка стола непрерывна во все стороны: она не заканчивается на границах рабочей области, а прокручивается и масштабируется вместе с рабочей поверхностью. Элементы можно уводить далеко за пределы стартового экрана.

Клавиша — самостоятельный элемент. У неё есть код (`T`, `F`, `Space` и т. д.) и список ссылок на цели. Связь видна как настоящая линия со стрелкой, идущая от клавиши к цели; на линии подписана клавиша. Одна клавиша может быть связана с несколькими командами и предметами и запускает их по очереди.

Порядок работы:

1. Нажмите `+` и выберите «клавиша» или нажмите клавишу на интерактивной схеме.
2. Клавиша сразу появляется на столе.
3. Включите `→` («связать»), выберите клавишу, затем нажимайте цели, чтобы добавить или убрать связь.
4. Выключите `→`. Пока стол открыт, связанные клавиши работают; в основной вкладке работают те, что не заняты базовым управлением.

Схема «клавиши» — интерактивная визуализация клавиатуры: нажатие на кнопку клавиши сразу добавляет её на стол, а у уже добавленных клавиш показывает число связей и позволяет выбрать их в режиме `→`. Это не декоративная картинка.

Масштаб стола регулируется колесом, щипком и кнопками в диапазоне 18–320%; ЛКМ по пустому месту двигает рабочую поверхность. Кнопка `100%` сбрасывает и масштаб, и положение. Элементы, связи и привязки сохраняются в `localStorage`.

## Мир и генерация

Мир бесконечен и строится лениво. Стартовый чанк `(0,0)` создаётся сразу, потому что в нём находятся Скрижаль, сюжетные комнаты и точка появления. Остальные чанки появляются, когда игрок или карта приближаются к ним.

- Чанк — сетка комнат `5×5`.
- Комната — `21×17` тайлов, зазор между комнатами — 6 тайлов.
- Размер чанка в тайлах — `135×115`.
- Структура каждого чанка детерминирована парой `seed + координаты чанка`, поэтому один и тот же мир восстанавливается из сохранения, а разные seed дают разные лабиринты.
- Внутри чанка комнаты соединяются связным «расплетённым» графом с петлями; на границах чанков есть проходы. Тупики у обычных комнат убираются, у Круга Очарования остаётся ровно один вход.
- Проходы в стенах комнат имеют ширину от 1 до 12 тайлов и располагаются в произвольном месте стены, а не строго по центру стороны. Поэтому лабиринт получается менее линейным.
- Сюжетные комнаты закреплены в домашнем чанке: Скрижаль, Слепой зал, Низкий свод, Круг Очарования, Кладовая и Тихий перекрёсток. У первой процедурной сюжетной комнаты шанс появления — 25%, у последующих ниже.
- Фоновые комнаты получают имена, колонны и находки из того же seed; игрок физически переходит между комнатами и может возвращаться.

Карта терминала показывает окно 7×5 комнат вокруг текущей. Поскольку мир не имеет границы, окно переезжает вместе с игроком, а не изображает весь Лабиринт целиком.

### Выживание

Комнаты `beetle` и `umbrella` — не бой с врагами, а внезапное выживание за аксолотля. Оно начинается само при входе в комнату, без согласия игрока и без отдельной кнопки подтверждения. Цель — продержаться до конца таймера, а не снять здоровье противника: у врагов нет полосы HP, зато есть вода, течение и плотный поток снарядов.

- `Shift`, `Space`, `E` или кнопка `A` геймпада — рывок, чтобы уйти из-под удара.
- `F` или кнопка `X` геймпада — раскрыть зонт и отразить снаряд.
- Волны чередуются: края, веер, кольцо, спираль, дождь, перекрёстный огонь и самонаведение. Чем дольше держишься, тем активнее напор.
- Успех — дожить до конца таймера; гибель и выход из воды работают по общим правилам, награда и сюжетный флаг выдаются только за успех.

## Что работает в прототипе

- Полноэкранная компоновка: игра сверху, терминал снизу; широкие экраны получают больше мира по горизонтали, узкие — сенсорные кнопки.
- Восьминаправленный спрайт Zemic: восемь групп по четыре кадра шага — вниз, вверх, влево, вправо и четыре диагонали.
- Скрижаль — центр мира и точка появления после гибели, но не «база» и не безопасная зона.
- Бесконечный ленивый Лабиринт по чанкам с детерминированным seed. Новый мир создаётся командой `новая игра`.
- «Слепой зал» остался атмосферной комнатой без теней и урона: он проверяет память о направлении, а не реакцию.
- Пыль и мелкие частицы живут в координатах мира и не приклеены к экрану; при ходьбе они не перегенерируются, а остаются на месте.
- Рюкзак с предметами, картой, мелком и картой «Очарование». Предметы можно выносить на стол.
- Гибель возвращает Zemic к Скрижали, а рюкзак со всем содержимым остаётся в месте гибели. Повторная гибель не удаляет прежние рюкзаки: каждый остаётся отдельным объектом, пока его не подберут.
- Терминал с очередью сообщений, настраиваемой скоростью печати, единой типографикой, переопределениями для терминала и стола, записью действий и историей команд. Команда `история` показывает буфер введённых команд. Сюжет, гибель и результат испытания выводятся в общий лог.
- Первое системное сообщение объединяет версию ядра и сборки, время загрузки мира, число комнат и чанков, seed и справку по управлению.
- Стол поддерживает свободное размещение, перетаскивание, удаление, бесконечную сетку, элементы из предметов, команды и отдельные клавиши. Одна клавиша может запускать несколько целей; связи рисуются линиями со стрелками. Состояние стола и привязки сохраняются. Схемы управления включают клавиатуру, геймпад, телефон и мышь; закрытие стола — крестиком `×`.
- Интерактивная схема клавиатуры на столе добавляет клавишу на стол одним нажатием; живые клавиши сразу запускают свои цели. Отдельного ядра управления с подсветкой клавиш и строки движения с кнопками-стрелками больше нет.
- Сохранение, загрузка, импорт и экспорт мира доступны командами и кнопками в `настройки` → «Данные»; в интерфейс терминала они не вынесены. Именованные слоты хранятся отдельно от автосохранения, их можно выбирать, переименовывать и удалять.
- Переключение языка командой `язык` (русский/английский/немецкий) меняет интерфейс, терминал и доступные псевдонимы команд.
- Внезапное выживание за аксолотля: вход в комнату `beetle` или `umbrella` сразу запускает воду и поток снарядов без согласия игрока. Нужно продержаться до конца таймера, уходя рывком и отражая снаряды зонтом; волны краёв, веера, кольца, спирали, дождя, перекрёстного огня и самонаведения чередуются.
- Испытание «Круг Очарования»: 35 секунд, три искры, три временные печати, нужно закрыть не меньше двух. Искры — health-подобный ресурс только внутри испытания; при их исчерпании Zemic погибает по общим правилам. Если время истекло без нужного числа печатей, испытание можно повторить без гибели и без потери предметов.
- После успешного испытания в центре комнаты появляется карта «Очарование». Её можно взять, положить на стол и вызвать командой `очаровать`.
- Зацикленный фоновый трек, общий для всех комнат; команда `музыка` и музыкальный плеер в настройках позволяют включить, поставить на паузу, остановить трек, перемотать нажатием по волне, изменить громкость или выключить звук; плеер рисует полную волновую дорожку всего трека.
- Сохранение прогресса в `localStorage`: seed, позиция, флаги, посещённые комнаты, предметы, рюкзаки, метки, элементы стола, связи клавиш и просмотренные сюжетные сцены. Состояние испытания намеренно не сохраняется между перезагрузками.

## Сборка и версия

Игра остаётся статической и не требует сборщика. Небольшой скрипт `build.js` увеличивает номер сборки и записывает его в `js/build-info.js`:

```bash
node build.js
```

После запуска номер сборки в `js/build-info.js` увеличивается на единицу, а версия берётся из `js/config.js` (`version`). В игре первое системное сообщение показывает `Версия ядра: <версия> · сборка <номер>`, так что версию можно проверить прямо в терминале. Запускать `build.js` нужно после изменений, которые должны попасть в новую сборку.

- общий размер шрифта масштабирует интерфейс, переопределение терминала действует локально, кнопка «авто» и общий сброс работают, настройки сохраняются;
- широкий экран 1280×800 заполняется целиком и расширяет игровую область по горизонтали; узкий экран 440×960 тоже заполняется целиком;
- восемь направлений дают восемь разных групп кадров, кадры шага остаются внутри своей группы из четырёх;
- пыль закреплена в координатах мира: при сдвиге камеры общие частицы сохраняют положение и размер;
- у мира больше нет теней-врагов, «Слепой зал» помечен тишиной, его текст не пугает тенями;
- новый мир строится лениво: сначала один чанк, после `ensureChunk` — два; одинаковый seed даёт одинаковую структуру, другой seed — другой лабиринт; все созданные комнаты достижимы, у Круга один вход;
- после перезагрузки сохраняются открытия, элементы стола, клавиши и их связи, логгирование и размер шрифта;
- именованные слоты сохраняют, загружают, переименовывают и удаляют мир отдельно от автосохранения; импорт JSON восстанавливает мир, экспорт скачивает файл;
- вход в комнату выживания запускает аксолотля без подтверждения, рывок и зонт работают, успех зависит от таймера, а не от здоровья врага;
- старая привязка `element.key` мигрирует в отдельный элемент-клавишу, собирает обе цели и удаляет поле `key` у целей;
- испытание открывает игровую сцену, провал и успех сразу возвращают в `main` и выводятся в лог; экрана результата и кнопки «Дальше» нет;
- в ходе прогона не возникло JS-ошибок.

Что не проверено:

- Полное 35-секундное прохождение испытания вручную с реальным уклонением. Ветки успеха и провала проверялись принудительным завершением через debug API.
- Реальные iOS/Safari, Android и физические сенсорные устройства; щипок, перетаскивание разделителя пальцем и панорамирование проверены синтетическими pointer-событиями.
- Подключение физического геймпада: схема и опрос Gamepad API реализованы, но проверялись без реального устройства.
- Слышимость трека и подбор громкости на реальных колонках/наушниках.
- Публикация на живом GitHub Pages.

## Сохранение и отладка

Ключ сохранения: `zqwy.labyrinth.prototype.v1`. Версия сохранения: `1`. Seed нового мира создаётся случайно при первом запуске и при команде `новая игра`; сохранённый seed восстанавливается при следующем открытии. Пропорция разделителя хранится отдельно в `zqwy.labyrinth.split.v1`, настройки терминала — в `zqwy.labyrinth.terminal.v1`. Элементы стола, клавиши и их связи входят в основное сохранение.

Сохранение, загрузка, импорт и экспорт доступны командами `сохранить`, `загрузить`, `импорт`, `экспорт` и кнопками в `настройки` → «Данные». Экспорт скачивает JSON-файл `zqwy-world-<seed>.json` с состоянием мира, seed, координатами чанков и метаданными; импорт принимает такой же файл или JSON именованного слота и восстанавливает мир без перезагрузки страницы.

Именованные сохранения лежат отдельно от автосохранения в ключе `zqwy.labyrinth.slots.v1`. В настройках можно выбрать слот из списка, сохранить текущий мир под именем, загрузить, переименовать или удалить его. Имя ограничено 40 символами, слоты сортируются по времени сохранения. Те же действия доступны командами `слоты`, `сохранить слот <имя>`, `загрузить слот <имя>`, `переименовать слот <старое> → <новое>` и `удалить слот <имя>`.

При `?debug=1` в URL устанавливается `window.__zqwy` — только для разработки и проверок. Он умеет возвращать снимок состояния, телепортировать игрока, переходить в комнату по роли, выдавать предмет, вызывать гибель, запускать и завершать испытание, закрывать представления, создавать новый мир, управлять логгированием, читать сюжетное дерево, добавлять элементы и клавиши, связывать и развязывать цели, двигать и масштабировать стол, сохранять состояние. В обычном запуске API отсутствует.

## Заглушки и следующий этап

- «Очарование» остаётся нейтральной заглушкой: команда `очаровать` отвечает, что способность ещё не подключена; эффекта, ограничения или баланса нет.
- Испытание имеет базовую настройку (35 секунд, 3 искры, 3 печати, порог 2) и требует отдельного балансировочного прохода.
- Мир генерируется бесконечно, но сюжетных комнат и уникальных событий пока конечный набор; фоновые комнаты различаются структурой и именами.
- Нет внешних библиотек, сборщика и серверной части; всё работает на нативных HTML/CSS/JS.

## Важные открытые решения

1. **Останавливать ли игровое время при открытом столе.** Сейчас время останавливается, как и при открытом рюкзаке/карте. В доступном Godot-проекте это не подтверждено.
2. **Эффект и стоимость «Очарования».** Механика предмета, размещения, вызова и ответа терминала готова; сам эффект, ограничения и баланс должны проектироваться отдельным модулем.
3. **Нужны ли разные треки для комнат.** Сейчас один зацикленный файл на весь Лабиринт; cue-таблица готова к разделению, но новые файлы не добавлялись.
